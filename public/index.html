Ресурсы Linux и Windows

Для CPU, памяти и диска запустите agent.mjs на сервере. В новой проверке выберите «Агент» и укажите его адрес и токен.

HTTP и TCP работают без агента. TCP проверяет открытый порт; HTTP — код ответа. Инструкция по установке агента — в README.

Служба мониторинга

Для постоянного мониторинга разместите службу отдельно от prod. Если остановится сама служба, она не сможет обнаружить или отправить сбой.
